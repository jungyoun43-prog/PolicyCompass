Recommended Flow

Start with visual comparison, not prose. The goal is to choose a direction with confidence before any frontend work begins.

  1. Search by brand, mood, category, or product type.
  2. Open the light or dark preview at full size when a card looks promising.
  3. Click Use This Design to send that style into the composer.
  4. Fill in the product brief, constraints, and target platform.
  5. Copy the generated prompt into Codex or Claude, then build with the chosen `DESIGN.md`.
