# Jev 약제 급여 검토

승인된 범위: 기존 모델 선택 목록에 Jev 1.13을 추가한다. Jev를 고르면
○ 충족 / △ 판정 제한 / ✕ 미충족 판정과 세 선택지의 확률만 표시한다.
기존 생성 모델의 설명문과 기준별 표는 유지한다.

서버는 기존 OpenRouter 키로 `/api/alpha/decisions`에 choice 질문을 보낸다.
고시와 환자 데이터, 운영자가 편집한 입력은 기존 검토 경로를 재사용한다.
기본 Jev 지시문에는 설명문 출력 요구를 넣지 않는다.

서버와 결과 병합에서 선택지, 유한한 0~1 확률, 확률 합계 및 선택 결과의
일관성을 확인한다. 오류는 기존 재시도와 규칙 판정 복귀 경로를 따른다.
검증된 Jev 판정은 기존 고시 기반 생성 모델처럼 그대로 표시하며,
규칙 표나 요약을 Jev가 작성한 근거로 표시하지 않는다.

확률은 모델의 선택 확률로 표시하며 실제 삭감률로 표현하지 않는다.
검증: 요청 형식·입력 편집 반영·세 판정·잘못된 응답·오류 복귀·기존 모델
경로를 테스트하고, 결과 컴포넌트의 판정·확률 렌더링을 확인한다.
