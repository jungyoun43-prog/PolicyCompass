의료진과 개인 사이의 기록 전달 방식

의료진이 환자용 파일과 일회성 코드를 따로 전달하면, 개인이 직접 대조해 가져옵니다.

  1. 1EMR 서명·정제식별정보·원문 메모 제외
  2. 2환자 확인·가져오기파일과 별도 확인 코드 대조
  3. 3진료에서 확인선택한 질문을 직접 전달
이 선택 화면은 무상태입니다. 건강정보 입력란, 브라우저 저장, 서버 전송, 자동 역할 감지가 없습니다.
