LOCAL SNAPSHOTS

나의 건강 지도 기록

최근 두 기록을 비교하며 저장된 Journey 기록은 바꾸지 않습니다.

FIRST SNAPSHOT · 01

첫 기록을 남기면 다음 시점부터 변화가 이어집니다.

첫 지도 만들기환자용 기록 가져오기 · 내 신호 직접 추가 예시로 흐름 보기가져온 기록과 분리 · 현재 탭에서만 유지

현재 지도의 질환 항목·입력 확인 신호·측정값만 로컬 기준점으로 저장합니다. VitaGraph는 기록 차이를 보여 주지만 원인·호전·악화를 판단하지 않습니다.

  1. 1
    정제 기록 가져오기환자용 파일과 별도 확인 코드를 직접 대조
  2. 2
    내 입력 확인 신호·시점직접 더한 항목과 기록 날짜를 대조
  3. 3
    Journey에 저장다음 기록부터 같은 항목의 차이를 비교

예시 모드에서는 가져온 실제 기록을 표시하거나 내보내지 않고 Journey에도 저장하지 않습니다.

LOCAL DATA TOOLS

Journey 백업·복원

Journey는 다른 기기와 자동 동기화되지 않습니다. 여기의 JSON은 변화 기록을 옮기기 위한 개인 백업이며 환자용 기록 가져오기 파일이 아닙니다. 복원하면 현재 Journey 전체를 교체합니다.

MEASUREMENT DELTA

같은 단위 측정값 변화

최근 두 기록에서 이름과 단위가 같은 숫자만 계산합니다. 차이의 원인이나 호전·악화를 판단하지 않습니다.

표시·수치 변화는 질환의 발생·원인·호전·완치를 뜻하지 않습니다. EMR에서 정제된 기록과 직접 입력한 상태 사이의 표시 차이입니다.

VitaGraph Personal 의학적 진단이나 처방을 제공하지 않습니다.
