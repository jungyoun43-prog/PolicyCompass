의료진이 내보낸 환자용 기록은 파일과 별도 확인 코드를 받은 뒤 내가 직접 가져옵니다. 내가 남긴 최근 변화와 함께 읽고, 다음 진료에서 서로 확인할 질문까지 준비합니다.

개인용 앱 · EMR 업무 공간과 분리 · 식별정보·원문 메모 제외 · 임상 기록을 직접 바꾸지 않음 · 진단·처방 아님

질문은 검증 가능한 규칙으로 먼저 정리합니다. 선택적 외부 모델은 전송 범위를 확인하고 해당 실행에 동의한 경우에만 사용합니다. Journey는 선택한 기록만 이 브라우저에 저장합니다.

FIRST VISIT · 4 STEPS

처음이라면 이 순서만 따라가세요.

의료진에게 받은 환자용 파일이 아직 없어도 예시로 전체 흐름을 먼저 볼 수 있습니다. 예시는 가져온 기록이나 의료진 브리프와 섞이지 않습니다.

  1. 01
    정제 기록 가져오기

    의료진에게 받은 환자용 파일과 별도 확인 코드를 직접 대조해 가져오거나 안전한 예시를 엽니다.

  2. 02
    신호 확인

    지도에서 기록된 항목과 직접 선택한 항목을 구분합니다.

  3. 03
    연결 살펴보기

    기록 근거와 키워드 기반 추론 관계를 따로 읽습니다.

  4. 04
    질문 확인·직접 전달

    규칙 기반 질문 초안을 확인한 뒤 필요한 질문을 복사하거나 진료에서 직접 보여줍니다.

01
파일·확인 코드로 가져오기

대상 환자를 대조한 뒤 식별정보와 원문 메모를 뺀 확정 항목만 직접 가져옵니다.

02
직접 받는 최소 사본

의료진이 내보낸 환자용 파일과 별도 확인 코드를 직접 대조해 가져옵니다.

03
규칙 기반 질문 정리

기본 질문은 규칙으로 만들고, 외부 모델은 전송 범위를 확인·동의한 실행에만 사용합니다.

ONE RECORD, ONE CONVERSATION

그래프를 만드는 데서 끝내지 않습니다.

서명·확정 기록은 환자용 파일로 직접 받고, 환자는 선택한 질문을 복사하거나 진료에서 보여주며 대화를 준비합니다.

  1. 01

    정제 기록 가져오기

    의료진이 내보낸 환자용 파일과 별도 확인 코드를 대조한 뒤, 파일에 의료진 확정으로 표시된 질환과 최종 측정값을 직접 가져옵니다. 발행기관·변조 여부는 검증되지 않습니다.

  2. 02

    신호·근거 확인

    EMR 기록, 내가 더한 신호, 문헌 기반 추론을 구분해 읽습니다.

  3. 03

    질문 직접 전달

    환자는 물어볼 질문을 고른 뒤 복사하거나 진료에서 직접 보여줍니다.
